How This Works

The 15-minute shape, every day

Every module uses the same four beats. Agents learn the rhythm once, then the content can change without anybody having to relearn the format.

The four beats that make up every 15-minute module
Minutes Beat What happens
0–2 Hook One real number or one real call moment. No agenda, no recap of yesterday.
2–7 Teach One idea only. If it needs two ideas, it needs two days.
7–12 Drill Everybody says something out loud. Pairs, round-robin, or a live listen.
12–15 Commit One behaviour for today and one number to watch. Then straight onto the phones.
Why one topic per week Four sessions on one subject builds a habit. Four sessions on four subjects builds a newsletter. Each week ends with a behaviour that is already on the phones by Thursday afternoon.

    Editing This Page

    Every lesson plan lives in one file, assets/curriculum-data.js. Nothing in the markup needs touching to change the curriculum.

    • Change a lesson plan: edit the days entry for that week.
    • Reorder the programme: move a week object inside PROGRAMME.weeks. Week numbers and dates follow position automatically.
    • Add a week: add another object with four days. The chart widens itself.
    • Change the start date permanently: edit startMonday.
    • Move a module between statuses: change status to built, adapt or create as work gets done. The tiles and the chart both update.

    Deep links work per module, so #w1d1 opens Week 1 Monday directly. Useful for pasting a single lesson plan into Slack the night before.
